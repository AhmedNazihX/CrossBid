Button: the one action control — primary blue for the single main action per region, secondary (white/bordered) for everything else.

```jsx
<Button variant="primary" icon={<PlusIcon/>}>Start analysis</Button>
<Button variant="secondary" size="sm">View run</Button>
```

Variants: primary, secondary, ghost, inverse (black, marketing CTA), danger. Sizes sm 32 / md 40 / lg 48. Labels ≤3 words, sentence case, no exclamation.
