# CrossBid web app kit
Recreation of the bidder workspace, modeled on GovDash's app shell (canvas sidebar + single white content frame).
Screens: Dashboard (greeting, ask bar, quick actions, KPIs, upcoming tenders), Runs (agent activity chart, status donut, filters, run cards), Compliance matrix (requirement table with citations + evidence state), Verdict review (human confirmation).
Files: index.html (shell + routing), Shell.jsx, Icons.jsx, data.js, Dashboard.jsx, Runs.jsx, Matrix.jsx, Verdict.jsx.
