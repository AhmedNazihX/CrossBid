# CrossBid marketing website kit
Landing page modeled on govdash.com's structure: sticky glass nav, centered hero with product frame, trust line, feature grid, "how it works" steps, trust/advisory section, CTA band, footer.
Files: index.html (mounts), Nav.jsx, Hero.jsx, Sections.jsx, Footer.jsx. Uses DS Button/Badge/Tag/VerdictChip via ../loader.js.
